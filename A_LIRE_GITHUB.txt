OPUS ELEC - CONSIGNATION ÉLECTRIQUE v1.2 - VERSION RENFORCÉE CONTRÔLE

Évolutions destinées à améliorer la traçabilité pour les chantiers importants et les contrôles externes :

- date + heure de consignation ;
- domaine de tension BT / HTA ;
- chargé d'exploitation / donneur d'ordre ;
- exploitation / service ;
- habilitation du chargé de consignation ;
- identification des sources de réalimentation possibles :
  réseau principal, groupe, UPS, photovoltaïque, batteries, aval, etc. ;
- confirmation que toutes les sources amont / aval ont été prises en compte ;
- repère exact de l'organe de séparation ;
- repère du cadenas / dispositif de condamnation ;
- signalisation de condamnation détaillée ;
- étape IDENTIFICATION ajoutée explicitement ;
- repère exact de la partie consignée ;
- identification du VAT utilisé ;
- confirmation VAT au lieu de travail ;
- confirmation VAT sur tous les conducteurs actifs, neutre compris ;
- MALT / court-circuit : réalisée / non requise en BT selon conditions / non applicable ;
- gestion des énergies résiduelles ;
- date et heure de délivrance de l'attestation ;
- confirmation de remise au chargé de travaux.

Références de conception :
- Code du travail R4544-9 et R4544-10 ;
- NF C 18-510 COMPIL 2 (juin 2023) ;
- INRS ED 6109.

IMPORTANT :
L'application facilite la traçabilité documentaire. Elle ne décide pas à la place du chargé de consignation
si une étape est requise ou non dans une situation donnée, et ne remplace ni l'analyse de risque, ni le titre
d'habilitation, ni les prescriptions applicables à l'installation.
